# Scripting Surface

Scripting is a semantic/object-model observation surface. It is especially useful for project/item/layer/property identity, reflection, menu commands and controlled project generation.

Important non-obvious behavior already known: indexed PropertyGroups can be recreated after insertion, invalidating script references. This is valuable evidence about host-side container/handle semantics.
